LOGO: images/logo.png is only 100 x 99 pixels, so it looks blurry when enlarged.
To make the logo (and the words around its ring) clear:
1. Open this link in your browser:  https://files.cdn-files-a.com/uploads/12608521/800_6af0a808cb27f.png
   (it is the 800-pixel logo from your Site123 site) - or use your original logo file if you have one (the bigger the better, 800 px or more).
2. Right-click the picture, choose "Save image as", and name it  logo-large.png
3. Put it in this images folder, replacing the existing logo-large.png.
The website uses logo-large.png automatically. Refresh the page (Ctrl+Shift+R).
