HOW TO UPDATE YOUR WEBSITE (admin only)
1. Open admin.html, enter the admin passcode (first passcode: PEM-Admin-2026 - change it in the Security tab straight away).
2. Edit services, announcements, Thanksgiving, sermons, giving details, contacts. Click Preview to check.
3. Click "Download content.js".
4. Replace the file data/content.js in your website folder (or on your hosting) with the downloaded one.
Visitors cannot change anything: edits only go live when you upload content.js.
Pages: index, about, ministries, services, sermons, give, contact. Photos are in images/.
